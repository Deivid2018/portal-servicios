# Portal Servicios 🚀

Portal web profesional para vender servicios con formulario de contacto y llamadas de seguimiento.

## 📋 Características

✅ **Página Principal** - Presentación con hero section, servicios destacados y formulario
✅ **Página de Servicios** - Listado detallado de todos los servicios
✅ **Página de Contacto** - Formulario completo para solicitar información
✅ **Diseño Responsive** - Se adapta a dispositivos móviles, tablets y desktops
✅ **Formulario Funcional** - Validación de campos y mensaje de confirmación
✅ **Navegación Clara** - Menú intuitivo y enlaces internos

## 📁 Estructura del Proyecto

```
portal-servicios/
├── index.html          # Página principal
├── servicios.html      # Página de servicios
├── contacto.html       # Página de contacto
├── css/
│   └── styles.css      # Estilos compartidos
├── js/
│   └── script.js       # Funcionalidad interactiva
└── README.md           # Este archivo
```

## 🚀 Cómo Usar

### Opción 1: Abrir localmente
1. Descarga o clona el repositorio
2. Abre `index.html` en tu navegador
3. ¡Listo! La web está lista para usar

### Opción 2: Ver en línea (GitHub Pages)
Ve a tu repositorio → Settings → Pages → Selecciona "main branch" → Guarda

## 🎨 Personalización

Puedes editar fácilmente:

- **Información de contacto** - Cambia el teléfono, email y ubicación en los archivos HTML
- **Colores** - Modifica las variables CSS en `css/styles.css`
- **Texto y contenido** - Edita directamente los archivos HTML
- **Servicios** - Agrega o quita servicios en las secciones correspondientes

## 📞 Secciones del Formulario

- Nombre
- Empresa (opcional)
- Email
- Teléfono
- Servicio de interés
- Mensaje
- Checkbox de términos y condiciones
